# Portfolio Website for Mr. Sourav Das

This repository contains the source code for the portfolio website of Mr. Sourav Das. The website showcases his professional background, achievements, and contact information.

Link: https://www.sourav-das.com/

## Table of Contents

- [Introduction](#introduction)
- [Features](#features)
- [File Structure](#file-structure)
- [Usage](#usage)

## Introduction

This portfolio website is designed to highlight the professional journey of Sourav Das, a Research Associate at the University of Kassel. The website includes sections such as Hero, About, Resume, and Contact, providing a comprehensive overview of his work and achievements.

## Features

- **Hero Section**: A welcoming section with a background image and social media links.
- **About Section**: Detailed information about Sourav Das, including his Ph.D. journey and upcoming plans.
- **Resume Download**: A button to download Sourav Das's resume.
- **Contact Information**: Links to social media profiles and a contact form.
- **Responsive Design**: The website is designed to be responsive and accessible on various devices.

## File Structure

- **index.html**: The main content of the website.
- **assets/**: Contains assets such as images, stylesheets, and scripts.
- **forms/**: Contains email.js implementation for contact form.

## Usage

To view the website locally, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/portfolio-website.git
   ```
2. Navigate to the repository directory:
   ```sh
   cd portfolio-website
   ```
3. Open the `index.html` file in a web browser.
